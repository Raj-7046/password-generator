# 🔐 Python Password Generator

A beginner-friendly Python project to generate secure and random passwords with customizable length. It ensures that each password includes at least one uppercase letter, one lowercase letter, one digit, and one special character to meet strong password standards.

---

## 📌 Features

- Random password generation
- Ensures at least one of each: uppercase, lowercase, digit, and symbol
- Length can be customized
- Uses only built-in Python libraries (`random`, `string`)

---

## 💻 Technologies Used

- Python 3.x
- Built-in modules: `random`, `string`

---

## 🚀 How to Run

1. Clone this repo:
```bash
git clone https://github.com/yourusername/password-generator.git
cd password-generator
```

2. Run the script:
```bash
python password_generator.py
```
